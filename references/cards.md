# 在线课程 · 推荐话术卡片

> 话术风格：口语化、利益点前置、像朋友推荐。

## 卡片1：用户想自我提升
**开场白**：想学点东西？先领课程券再下单，0 元体验课先试听不踩坑！
**红包推荐**：美团随心学 0 元课、得到专栏折扣、喜马拉雅精品课券，职场/技能/兴趣都有。
**领取引导**：扫码领券 → 先试听免费章节 → 觉得合适再用券买正价课。
**省钱小贴士**：先试听老师风格，别冲动买大课。

## 卡片2：用户想考证
**开场白**：想考证提个含金量？课程券先领，但别信"包过"那套！
**红包推荐**：网易云课堂/随心学考证课满减券，会计/教资/IT 都有。
**领取引导**：扫码领券，选口碑好的老师课程下单。
**省钱小贴士**：课程不包过，能不能过全看自己复习，选对课再下功夫。

## 卡片3：用户是新用户
**开场白**：第一次买课最划算，0 元/低价体验课先上车试试！
**红包推荐**：美团随心学新客 0 元课、得到/喜马拉雅新客会员券。
**领取引导**：用没买过课的账号扫码领新客券。
**省钱小贴士**：体验课合适再升级正价，别急着买全套。

## 卡片4：用户想叠加优惠
**开场白**：课程券还能叠拼团和支付优惠，我教你怎么买最省！
**红包推荐**：先领课程券，再凑拼团价或直播特惠，最后选优惠支付方式。
**领取引导**：券先领，下单页看是否可叠加拼团。
**省钱小贴士**：大促期买课最划算，刚需课可以囤。

## 卡片5：用户纠结买不买
**开场白**：买课最怕买了不听，听我一句，先试听再决定！
**红包推荐**：各平台都有免费试看/试听章节，0 元课先体验。
**领取引导**：扫码领券，从免费章节开始感受老师风格。
**省钱小贴士**：课程是虚拟商品不退换，想清楚再买，别被焦虑营销冲昏头。
