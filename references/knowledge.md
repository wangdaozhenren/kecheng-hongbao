# 在线课程 · 平台规则与叠加指南

> 覆盖平台：美团随心学、得到、喜马拉雅、网易云课堂（在线课程/知识付费）。

## 一、各平台红包规则

### 美团随心学
- **领取条件**：新客 0 元课/低价体验课、老客技能课/考证课优惠券。
- **使用门槛**：限平台内课程，多为立减券或满减券；部分券限指定类目（职场/考证/兴趣）。
- **有效期**：券码 7~30 天。
- **是否可叠加**：券与平台活动价可叠，0 元体验课通常不与付费券叠加。

### 得到
- **领取条件**：新客听书/课程体验券、老客专栏/课程折扣券。
- **使用门槛**：限得到 App 内课程/听书会员，部分为联合会员。
- **有效期**：券码 15~30 天。
- **是否可叠加**：券与会员权益视活动互斥。

### 喜马拉雅
- **领取条件**：新客会员/课程券、老客精品课折扣、听书会员券。
- **使用门槛**：限音频课程/会员，部分限专辑。
- **有效期**：券码 7~30 天。
- **是否可叠加**：券与会员开通优惠可叠。

### 网易云课堂
- **领取条件**：新客课程券、老客技能/考证课满减。
- **使用门槛**：限平台内课程，满减门槛常见。
- **有效期**：券码 15~30 天。
- **是否可叠加**：券与课程活动价可叠。

## 二、红包叠加逻辑
- **叠加顺序**：课程券码 → 平台活动价/拼团价 → 支付优惠。
- **先试听再买**：绝大多数课程有免费试看/试听章节，先听老师风格是否适合再用券买正价课。
- **拼团/直播更便宜**：拼团价、直播特惠常比券后价更低，大促期入手最划算。

## 三、新客与老客区别
- **新客专享**：0 元/低价体验课、首单大额券，用于引流。
- **老客可领**：专栏续费、进阶课优惠券、节日大促券。
- **新老客都能领**：平台通用课程券。

## 四、地域限制说明
- 在线课程全国通用，无城市限制；部分直播课/社群服务有时区或开班期限制。
- 以课程详情页"开课时间/服务形式"为准。

## 五、在线课程使用注意事项
1. **效果因人而异**：课程只是学习材料，能否学会、能否考过多取决于个人投入，不要指望"买了课就等于学会了"。
2. **不承诺考试通过**：任何考证课程都不保证你一定通过考试，通过与否取决于个人备考。
3. **虚拟商品不退换**：在线课程/音频会员属虚拟商品，购买后一经开通/兑换，原则上不退款、不退换。
4. **看清楚课程形式**：录播、直播、社群、1v1 服务价格差异大，下单前确认含哪些服务。
5. **理性购课**：别被"焦虑营销"裹挟，先试听、按需购买，买了不看等于浪费钱。
