# 在线课程红包助手 · 平台规则与叠加指南

> 覆盖平台：美团随心学、得到、喜马拉雅、网易云课堂（在线课程/知识付费）。

## 一、各平台红包规则

### 美团随心学
- **领取条件**：新客0元/低价体验课、老客技能课/考证课优惠券
- **使用门槛**：限平台内课程，多为立减或满减券；部分券限指定类目（职场/考证/兴趣）
- **有效期**：券码7~30天
- **是否可叠加**：券与平台活动价可叠，0元体验课通常不与付费券叠加

### 得到
- **领取条件**：新客听书/课程体验券、老客专栏/课程折扣券
- **使用门槛**：限得到App内课程/听书会员，部分为联合会员
- **有效期**：券码15~30天
- **是否可叠加**：券与会员权益视活动互斥

### 喜马拉雅
- **领取条件**：新客会员/课程券、老客精品课折扣、听书会员券
- **使用门槛**：限音频课程/会员，部分限专辑
- **有效期**：券码7~30天
- **是否可叠加**：券与会员开通优惠可叠

### 网易云课堂
- **领取条件**：新客课程券、老客技能/考证课满减
- **使用门槛**：限平台内课程，满减门槛常见
- **有效期**：券码15~30天
- **是否可叠加**：券与课程活动价可叠

## 二、红包叠加逻辑

- **叠加顺序**：课程券码 → 平台活动价/拼团价 → 支付优惠
- **先试听再买**：绝大多数课程有免费试看/试听章节，先听老师风格再用券买正价课
- **拼团/直播更便宜**：拼团价、直播特惠常比券后价更低，大促期入手最划算
- **新课首发折扣**：新课首发期常有折扣，刚需新课首发时入手

## 三、品类专属知识要点

### 3.1 课程有效期（避坑核心）
- **录播课**：购买后通常有**观看有效期**（如1年、2年内看完），不是永久有效
- 超过有效期课程可能锁定/无法观看，买前看清"有效期多久、能否续期"
- 别囤一堆过期不看的课，"买了=学了"是最大的坑

### 3.2 录播/直播/答疑区别
- **录播**：录好的视频，随时看、价格低、无实时答疑
- **直播**：实时授课，有互动和答疑、价格高、错过看回放
- **含答疑/社群/1v1**：服务越全越贵，下单前确认到底含哪些服务
- 别把录播课当成"有老师答疑"的课买

### 3.3 是否含答疑与配套服务
- 详情页会写"含答疑/社群/作业批改/证书"，没有写就不含
- 考证课要问清：是否有班主任、答疑群、题库、补考政策
- 服务类附加项值不值差价，按自己需求判断

### 3.4 退费规则（买课不囤课）
- 在线课程多为虚拟商品，**购买并开通后原则上不退不换**
- 部分课程有"7天无理由/未开课可退"，买前看清退费条款
- 建议：**先试听、按需买、不囤课**；大促囤课容易囤了不看，等于浪费
- 不承诺考试通过：任何"包过""保过"宣传都不可信

## 四、新客与老客区别

- **新客专享**：0元/低价体验课、首单大额券，用于引流
- **老客可领**：专栏续费、进阶课优惠券、节日大促券
- **新老客通用**：平台通用课程券
- 新客先用0元体验课试水，满意再升级正价，别急着买全套

## 五、避坑指南

1. **录播课有效期**：不是永久，超期锁定，别囤过期不看
2. **"包过/保过"是噱头**：考试能否通过取决于个人，别信承诺
3. **冲动囤课**：被焦虑营销裹挟买一堆不看的课，最浪费
4. **录播当直播买**：下单前确认课程形式和答疑服务
5. **虚拟商品不退**：买前试听、看清退费条款，开通后难退
